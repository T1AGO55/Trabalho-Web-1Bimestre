# 🌐 Trabalho Web - 1º Bimestre

Este projeto consiste no desenvolvimento de 15 páginas web interligadas, cada uma representando um exercício prático utilizando HTML e CSS.

O sistema foi estruturado de forma que todas as páginas estejam conectadas entre si, permitindo navegação contínua entre os exercícios.

---

## 🚀 Funcionalidades

* 15 páginas web interligadas
* Navegação entre todas as páginas
* Estrutura organizada por exercícios (Ex01 até Ex15)
* Layouts variados
* Página de **Mapa do Site** com estrutura hierárquica
* Design responsivo básico

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3

## 📦 Como Executar o Projeto

1. Clone o repositório:

```bash id="n2k1op"
git clone https://github.com/T1AGO55/Trabalho-Web-1Bimestre.git
```

2. Acesse a pasta:

```bash id="0p9wq2"

```

3. Inicie pelo arquivo principal:

* Abra o **Ex01 (Home)** no navegador
* Utilize os botões de navegação para acessar os demais exercícios

## 🗺️ Mapa do Site

O projeto inclui uma página de **Mapa do Site (Ex11)** que apresenta a estrutura completa das páginas.

Essa página utiliza:

* Lista não ordenada (`<ul>`)
* Estrutura em árvore
* Propriedade CSS `text-indent`
